# Probabilistic Graphlets Capture Biological Function in Probabilistic Molecular Networks

**Sergio Doria-Belenguer, Markus K. Youssef, René Böttcher, Noël Malod-Dognin and Nataša Pržulj**

This repository contains the Python and C++ scripts, as well as the datasets, for the paper "Probabilistic graphlets capture biological function in probabilistic molecular networks".

## Downloads

- [Datasets (Biological_Study.zip)](https://github.com/przulj-lab/Probabilistic_Graphlets/releases/download/v1.0/Biological_Study.zip)

## Probabilistic orbit counter

The probabilistic orbit counter can easily be applied using the Python code `Main_Orbit_Count.py`. It can also be run from the terminal, as set out in `Script_Parallel_Nodes_Count.py`.
